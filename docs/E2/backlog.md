# Backlog Priorizado — Pet & Gatô

| # | História | Critérios de aceite | Prioridade (MoSCoW) | Estimativa | Sprint alvo |
|---|---|---|---|---|---|
| 1 | Como recepcionista, quero cadastrar um tutor, para que eu consiga cadastrar o animal pertencente a ele. | - Campos obrigatórios: nome, cpf, cidade, e-mail, contato; <br> - Erro claro se CPF duplicado.<br> | Must | 1 | Sprint 1 |
| 2 | Como recepcionista, quero cadastrar um animal, para que ele possa ser propriamente agendado. | - Animal com único tutor; <br> - Campos obrigatórios: nome do animal, nome do tutor, tipo de animal, contato. | Must | 1 | Sprint 1 |
| 3 | Como recepcionista, quero garantir a segurança com exigência de senhas fortes, para que tenhamos segurança nos dados reservados e contas cadastradas. | - Senha exige mínimo de caracteres no cadastro <br> - Apresenta check de requisitos alcançados no cadastro <br> - Apresenta requisitos ainda não alcançados no cadastro | Must | 2 | Sprint 1 |
| 4 | Como veterinário, quero atualizar um prontuário com data de vacinação de um animal, para que eu saiba quando será a próxima dose. | - Vinculado a agenda da clínica; <br> - Data de início não pode ser posterior à data de fim. | Must | 5 | Sprint 3 |
| 5 | Como recepcionista, quero que o sistema garanta que não haja conflitos de agenda, para que não seja necessário checar manualmente. | - Sistema bloqueia agendamento com conflito <br> - Dispara pop-up informando o erro | Must | 1 | Sprint 2 |
| 6 | Como recepcionista, quero visualizar a lista de agendamentos do dia filtrada por status e veterinário, para gerenciar a fila de espera na recepção. | - Filtro padrão exibe os agendamentos da data atual; <br> - Permite filtrar por status (Agendado, Em Espera, Em Atendimento, Concluído, Cancelado) e por profissional. | Must | 5 | Sprint 2 |
| 7 | Como veterinário, quero consultar o histórico clínico completo de um pet (consultas anteriores, peso e tratamentos), para embasar meu diagnóstico no atendimento atual. | -Exibe lista cronológica de todos os atendimentos anteriores do animal <br> - Mostra data da consulta, nome do veterinário responsável, diagnóstico e prescrição | Must | 5 | Sprint 2 |
| 8 | Como veterinário, quero registrar o atendimento clínico do paciente (queixa, anamnese, diagnóstico e prescrição), para manter o prontuário eletrônico completo. |- Só permite iniciar o registro se a consulta estiver com status "Em Atendimento" <br> - Campos obrigatórios: peso do pet, queixa, diagnóstico e conduta | Must | 8 | Sprint 2 |
| 9 | Como veterinário, quero que a edição de prontuários seja realizado apenas pelo meu perfil, para que a recepção não tenha acesso a essa funcionalidade e seja garantida a confiabilidade dos tutores sobre a clínica. | - Perfis possuem acessos distintos | Must | 1 | Sprint 3 |
| 10 | Como recepcionista, quero que o banco de dados seja atualizado rapidamente com as informações que forem adicionadas, para que eu possa utiliza-las em outros processos em seguida, como agendamentos. | - Banco de dados atualizado rapidamente <br> - Front apresentando os dados recém publicados | Must | 1 | Sprint 4 |
| 11 | Como veterinário, quero que o sistema funcione de madrugada, para que possamos utiliza-lo em plantões. | - Sistema acessível em todos os horários | Must | 1 | Sprint 4 |
| 12 | Como veterinário, quero que o sistema verifique a carteirinha de vacinação do animal, para que não haja doses em excesso sendo prescritas e garanta o intervalo clínico mínimo. | - Sistema bloqueia doses duplicadas/abaixo do período mínimo <br> - Projeta o erro específico na tela <br> - Agenda a vacinação caso passar no check <br> - Atualiza a carteirinha de vacinação do animal com a data agendada | Should | 3 | Sprint 2 |
| 13 | Como veterinário, quero realizar anotações de plantão, para que a equipe registre a evolução do quadro. | - Somente uma atualização por plantão <br> - Uma anotação para cada animal. | Should | 5 | Sprint 3 |
| 14 | Como veterinário, quero ter acesso a lista de internações, cada caso e nível de gravidade. | - Identificação do Animal e Tutor <br> - Traz status atualizado <br> - O acesso ao caso desejado, traz as informações da internação de forma detalhada. | Should | 8 | Sprint 3 |
| 15 | Como recepcionista, quero que o sistema tenha uma tela inicial, para que eu possa ver o resumo dos clientes cadastrados, dos agendamentos e das internações | - Tela atualiza em tempo real | Should | 8 | Sprint 3 |
| 16 | Como recepcionista, quero que o sistema avise caso o tutor não tenha visitado a clínica no período de 1 ano, para que possamos garantir consultas periódicas (check-up) e a saúde do animal. | - Notificação é enviada se baseando na data da última consulta e dentro de horário comercial. <br> - Depende da integração das tecnologias FrontEnd x Banco de dados | Could | 8 | Sprint 3 |
| 17 | Como recepcionista, quero cadastrar observações adicionais sobre um tutor, para que consiga registrar informações relevantes que não estejam nos dados cadastrais. | - Permite adicionar observações ao cadastro do tutor <br> - Permite editar ou remover uma observação <br> - As observações ficam vinculadas ao tutor | Could | 3 | Sprint 4 |
| 18 | Como recepcionista, quero enviar lembretes automáticos de consultas aos tutores, para que as faltas sejam reduzidas e o acompanhamento dos agendamentos seja melhorado. | - Envia lembrete por e-mail ou SMS <br> - Informa data e horário da consulta <br> - Permite configurar o envio do lembrete | Could | 5 | Sprint 4 |
| 19 | Como veterinário, quero realizar videochamadas com os tutores, para que possa realizar consultas veterinárias de forma remota. | - Permite iniciar uma videochamada com o tutor <br> - Permite registrar a consulta no prontuário<br>- Exige conexão com a internet | Won't | - | - |
| 20 | Como veterinário, quero que os tutores tenham acesso ao sistema, para verificar atualizações no prontuário do animal caso eu atualize. | - Permite login do Tutor <br> - Sistema mostra a lista de animais cadastrados <br> - Mostra histórico de atualizações no caso do animal | Won't | - | - |
| 21 | Como veterinário, quero que o sistema apresente uma aba de estoque de recursos, para que possamos verificar os itens escassos e organizar a necessidade de um pedido. | - Estoque é editável, podendo incluir itens novos e alterar a quantidade | Won't | - | - |
| 22 | Como recepcionista, quero poder emitir uma carteirinha personalizada para os animais, para que nossa clínica traga o sentimento de exclusividade para os tutores. | - Carteirinha pré-pronta <br> - Personalização de foto, ícones e cores é possível. | Won't | - | - |
| 23 | Como recepcionista, quero que o sistema envie um lembrete dos aniversários dos animais, para que possamos disparar um email de parabenização. | - Lembrete sendo disparado no dia exato do aniversário, em horário comercial.  | Won't | - | - |
